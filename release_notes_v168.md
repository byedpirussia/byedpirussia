# Release Notes v1.6.8 — Полная трансформация VLESS (в стиле Happ) и глобальный DNS-центр WARP

Масштабное обновление **ByeDPI Russia v1.6.8** приносит кардинальные улучшения для VLESS-клиента и выносит управление DNS на абсолютно новый уровень!

---

### 🌐 1. Полная трансформация VLESS клиента (как в Happ / Hiddify):
- **Информация о подписке (Subscription User-Info)**:
  - Автоматический парсинг заголовков `Subscription-Userinfo` от провайдеров.
  - Отображение карточки с остатком трафика (например, `45.2 / 100.0 ГБ`) и оставшимся сроком действия подписки (`⏳ Осталось 22 дн.`).
- **Индивидуальная настройка конфигураций серверов**:
  - Кнопка редактирования параметров (`✏️`) у каждого сервера:
    - Название / заметка сервера, адрес хоста и порт.
    - UUID / пароль пользователя.
    - Параметры Reality & TLS: SNI, Public Key (`pbk`), Short ID (`sid`), Fingerprint (`fp`).
    - Путь `path` и заголовок `host` для WebSocket / HTTPUpgrade.
    - **Привязка стратегии ByeDPI (как в Happ)**: возможность назначить персональную стратегию десинхронизации (Fake Split, TLS Record и др.) к конкретному серверу!
- **Одиночный замер пинга для каждого сервера**:
  - Добавлена индивидуальная кнопка молнии (`⚡`) у каждого элемента списка серверов для быстрого замера пинга одного конкретного сервера без необходимости запуска общего тестирования.
- **Выбор метода замера пинга**:
  - Кнопка настроек метода (`⚙️`) рядом с кнопкой общего тестирования.
  - Поддержка 3 режимов измерения:
    1. **Proxy GET (Настоящий пинг)**: полный сквозной TLS Handshake с проверкой HTTP 204.
    2. **TCP Connect**: классическое быстрое подключение TCP-сокета.
    3. **ICMP**: системный эхо-пинг (`isReachable`) с fallback на TCP 443.
- **Надежность и отсутствие вылетов**:
  - Полная изоляция ошибок сети/сокетов при параллельном пакетном тестировании. Никаких сбоев и зависаний интерфейса.

---

### ⚡ 2. Глобальный раздел DNS для WARP:
- **Кнопка «⚙️ DNS» прямо на карточке WARP** главного экрана.
- **Интерактивный тест пинга DNS**:
  - Кнопка «⚡ Тест пинга» в диалоге DNS: отправка валидных DNS-запросов на порт 53 и измерение отклика каждого DNS-сервера с цветовой индикацией скорости.
- **Новое зеркало DNS AI**:
  - Добавлен сервер `DNS AI Зеркало CF (cf.dns-ai.ru)`.
- **Пользовательские DNS (Свой DNS)**:
  - Кнопка «+ Добавить свой DNS сервер»: можно ввести собственное название и адрес (IP или домен).
  - Свои DNS сохраняются в системе, их можно выбирать, тестировать пинг и удалять при необходимости.

Универсальное Android-приложение для восстановления доступа к заблокированным ресурсам (YouTube, Discord, Telegram и др.) без необходимости аренды зарубежных серверов и сложных настроек.

Приложение объединяет в себе три независимых инструмента, доступных прямо с главного экрана в 1 клик.

---

## ⚡ Основные возможности

### 1. 🛡️ ByeDPI (Десинхронизация ТСПУ)
- **Прямой доступ** к YouTube, Discord и сайтам без проксирования и VPN через зарубежные серверы (без падения скорости).
- **32 готовые стратегии** обхода (Split, Fake, OOB, Diso, Multidisorder и др.).
- **Автоподбор стратегии**: автоматический бенчмарк реальной доступности и задержки до YouTube и Discord для выбора идеальной комбинации под вашего провайдера.

### 2. ✈️ Telegram Proxy (MTProto over Cloudflare WebSocket)
- Встроенный автономный сервис проксирования Telegram прямо на устройстве (`127.0.0.1:1443`).
- Защищенный WebSocket-транспорт через Cloudflare CDN, устойчивый к блокировкам протокола MTProto.
- Мгновенное добавление прокси в Telegram в одно нажатие.

### 3. 🛡️ AmneziaWG Cloudflare WARP
- Полноценный встроенный VPN-туннель на базе ядра **AmneziaWG (WireGuard-Go)** с продвинутой обфускацией заголовков пакетов (AWG 2.0: `Jc`, `Jmin`, `Jmax`, `S1-S4`, `H1-H4`, `I1-I5`).
- **Встроенный генератор WARP**: создание бесплатного личного профиля Cloudflare WARP в один клик прямо из приложения.
- Экспорт и копирование `.conf` для использования в сторонних клиентах (AmneziaWG, WireGuard).

## 📱 Интерфейс приложения

- **Главный экран (Dashboard)**: минималистичный и удобный интерфейс с тремя крупными карточками для мгновенного включения нужного режима.
- **Продвинутые настройки**:
  - Ручной выбор из 32 стратегий DPI.
  - Живое тестирование стратегий с графиком задержек.
  - Управление конфигурацией WARP.
  - Тонкие настройки ядра ByeDPI (порты, IP, кастомные аргументы командной строки).

## 🛠️ Сборка проекта

### Требования:
- Android Studio Hedgehog (или новее) / JDK 17+
- Android SDK (API 34, Min SDK 26)
- NDK & CMake (для сборки нативных библиотек C/C++ и JNI)

### Сборка через командную строку:
```bash
# Windows
gradlew.bat assembleDebug

# Linux / macOS
./gradlew assembleDebug
```
Собранный APK будет находиться в папке: `app/build/outputs/apk/debug/app-debug.apk`.

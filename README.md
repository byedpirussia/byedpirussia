Универсальное Android-приложение для восстановления доступа к заблокированным ресурсам (YouTube, Discord, Telegram и др.) без необходимости аренды зарубежных серверов и сложных настроек.

Приложение объединяет в себе пять независимых инструментов (**ByeDPI**, **Telegram Proxy**, **AmneziaWG WARP**, **Xray VLESS / Shadowsocks / VMess / Trojan / Hysteria 2**, **OpenFLUX обход белых списков**), доступных прямо с главного экрана, полностью обновленный интерфейс **Material Design 3 (MT3)** с возможностью переключения на классический стиль, поддержку **цепочек прокси (Proxy Chaining)**, встроенные **проверенные подписки белых списков (ru-wbl)**, **шторку быстрых настроек (Quick Settings Tiles)**, многоязычный интерфейс (**Русский / English**), гибкое **раздельное туннелирование (Split Tunneling)** с автоматическим исключением российских приложений (банки, Госуслуги), мастер **первоначальной настройки**, а также **кастомизацию оформления** (динамические цвета Material You и акцентные темы).

## 🌟 Основные возможности

- 🎨 **Современный интерфейс Material Design 3**: интуитивная Hero-карточка общего статуса безопасности, быстрое отключение всех служб одной кнопкой, эргономичные карточки с переключателями `MaterialSwitch` и возможность переключиться в классический режим в Настройках.
- 🌊 **OpenFLUX (Обход белых списков / Б/С)**: инновационный метод обхода блокировок через разрешенные сервисы (Яндекс Документы, Яндекс Волга, Яндекс Доски, Mail.ru Документы, Cups.online Centrifugo, MAX/OneMe WebRTC, Direct). Поддержка VPN-туннеля и локального SOCKS5-прокси, импорт ссылок `openflux://`, пресеты из коробки.
- 🚀 **ByeDPI Engine**: локальная десинхронизация TCP/DNS/TLS, фрагментация пакетов, фейковые SNI и автоматический подбор рабочих параметров под вашего провайдера (32 стратегии).
- ✈️ **Telegram MTProto Proxy**: встроенный WebSocket-прокси через Cloudflare для обхода блокировок Telegram в 1 клик. **Постоянный секрет** — сохраняется в настройках и больше не сбрасывается при перезапуске!
- 🌐 **AmneziaWG Cloudflare WARP**: генерация и подключение обфусцированных WireGuard-туннелей (AWG 2.0). Включает **авто-переподключение**, замер пинга в реальном времени и расширенный выбор DNS-серверов с обходом ограничений Частного DNS (DoT).
- ⚡ **Xray Core (VLESS Reality / Trojan / Shadowsocks / VMess / Hysteria 2)**: поддержка подписок, одиночных ключей, пинг-теста и **встроенных подписок белых списков (ru-wbl)** для работы при жестких ограничениях мобильной связи.
- 🔗 **Цепочки прокси (Proxy Chaining)**: туннелирование трафика WARP через Shadowsocks / VLESS / Trojan и наоборот (`WARP over Proxy` / `Proxy over WARP`).
- 🎛️ **Quick Settings Tiles**: плитки быстрой активации ByeDPI, Telegram Proxy, WARP и OpenFLUX прямо из шторки Android.
- 🌍 **Многоязычность**: поддержка русского и английского языков с возможностью выбора при первом запуске или в меню «Настройки».
- 🔀 **Split Tunneling**: гибкая маршрутизация по приложениям с автоматическим исключением российских сервисов.

## 📖 Инструкция по использованию каждого метода

### 1. 🛡️ ByeDPI (Для YouTube, Discord и сайтов без потери скорости)
**Кому подходит**: Идеально для просмотра YouTube в 4K/60fps и голосовых каналов Discord на максимальной скорости вашего тарифа.
1. На главном экране переключите тумблер **ByeDPI**.
2. При первом запуске Android запросит стандартное разрешение на создание VPN-соединения — нажмите **«ОК»** (приложение работает локально на устройстве, никакой трафик на чужие серверы не уходит).
3. Статус сменится на `🟢 Активно`. Запустите YouTube или Discord — всё работает напрямую!
4. **Если YouTube не открывается или подтормаживает**:
   - Перейдите в **«Продвинутые настройки»** внизу экрана.
   - Нажмите **«⚡ Автоматический подбор стратегии»** — приложение само протестирует 32 комбинации и выберет ту, которая работает у вашего конкретного провайдера с минимальным пингом.
   - Либо выберите вручную пресет (например, *«OOB + Мультисплит»*, *«Split SNI»* или *«Fake Request»*).

---

### 2. ✈️ Telegram Proxy (MTProto over Cloudflare WebSocket)
**Кому подходит**: Для стабильной работы Telegram при блокировках и замедлениях мобильных операторов / провайдеров.
1. На главном экране переключите тумблер **Telegram Proxy**.
2. Локальный прокси-сервер запустится на адресе `127.0.0.1:1443` с вашим постоянным секретом.
3. Появится кнопка **«🚀 Применить в Telegram»** — нажмите её.
4. В открывшемся клиенте Telegram нажмите **«Включить этот прокси»** (Enable Proxy).
5. Теперь ваш Telegram подключен через Cloudflare WebSocket туннель! Секрет больше не сбрасывается при перезапусках.
6. **Управление секретом**: по долгому нажатию на кнопку *«Применить в Telegram»* доступен диалог с информацией о хосте, порте и секрете, возможность скопировать ссылку или при необходимости вручную перегенерировать секрет.
> **Примечание**: Telegram Proxy можно использовать одновременно с ByeDPI или WARP.

---

### 3. 🌐 AmneziaWG Cloudflare WARP (Полноценный VPN-туннель)
**Кому подходит**: Для любых заблокированных сервисов и сайтов, требующих полноценного туннелирования всего трафика через Cloudflare с обфускацией AWG 2.0.
1. На главном экране нажмите **«Включить WARP»**.
2. Разрешите создание VPN-соединения в Android.
3. Статус сменится на `🟢 Подключен`. Поддерживаются как числовые IP-эндпоинты, так и доменные имена (`engage.cloudflareclient.com:port`).
4. **Как обновить/сгенерировать новый WARP профиль**:
   - Откройте **«Продвинутые настройки»**.
   - В блоке **Конфигурация WARP** нажмите **«✨ Сгенерировать»** — приложение за пару секунд создаст свежий бесплатный профиль Cloudflare с уникальными ключами и защитными параметрами.
   - Вы также можете нажать **«📋 Скопировать»**, чтобы сохранить конфигурацию `.conf` или перенести её в стороннее приложение (AmneziaWG, WireGuard).
 
---
 
### 4. ⚡ Xray: VLESS / Shadowsocks / VMess / Trojan / Hysteria 2
**Кому подходит**: Для любых заблокированных сервисов и сайтов с использованием протоколов VLESS (Reality, TLS, WS, gRPC), Shadowsocks (`ss://`), VMess (`vmess://`), Trojan (`trojan://`) и Hysteria 2 (`hy2://`).
1. Нажмите **«Серверы и подписки»** на главном экране.
2. Добавьте свои ключи (`+ Ключ`) или ссылку на подписку (`+ Подписка`).
3. **Встроенные подписки Белых Списков (ru-wbl)**: нажмите кнопку **«📥 Подписки Б/С (ru-wbl)»** — приложение моментально добавит актуальные проверенные подписки (EtoNeYa, РосТуннель, Zieng2 и др.), специально отобранные для работы на мобильных сетях во время ограничений.
4. Подписки разделены по удобным горизонтальным вкладкам с возможностью обновления (`🔄 Обновить`) и удаления.
5. Нажмите **«⚡ Тест пинга»** — приложение проверит доступность серверов через генерацию URL-теста и отсортирует их от самого быстрого к медленному.
6. Выберите нужный сервер и переключите тумблер **VLESS** на главном экране.

---

### 5. 🔗 Цепочки прокси (Proxy Chaining)
**Кому подходит**: Для обхода блокировок WireGuard/WARP или скрытия реального IP сервера за Cloudflare.
1. Откройте **«Серверы и подписки»** -> кнопка **«🔗 Цепочка»**.
2. Введите название цепочки и выберите тип маршрутизации:
   - **WARP через Прокси (WARP -> Прокси -> Сайт)**: Cloudflare WARP подключается через выбранный зарубежный VLESS/Shadowsocks сервер.
   - **Прокси через WARP (Прокси -> WARP -> Сайт)**: Ваш VLESS/Trojan подключается через WARP туннель для маскировки под Cloudflare.
3. Сохраненная цепочка появится в общем списке серверов и подключается в один тап!

---

### 6. 🔀 Раздельное туннелирование (Split Tunneling) и исключение банков РФ
**Кому подходит**: Если вы хотите пустить в обход только отдельные приложения, либо гарантировать, что российские банки (Сбер, Т-Банк, Альфа, ВТБ) и Госуслуги не увидят VPN.
1. Откройте **«Продвинутые настройки»** -> **«Раздельное туннелирование»**.
2. Включите тумблер **«Автоматически исключать российские приложения»** — все российские банковские, государственные и системные сервисы будут автоматически направлены напрямую в обход VPN без детекта флага `TRANSPORT_VPN`.
3. Либо выберите ручной режим:
   - **Весь трафик устройства (без исключений)**
   - **Туннелировать только выбранные (Whitelist)**
   - **Туннелировать всё, кроме выбранных (Blacklist)**
4. Доступен поиск приложений, отметка российских приложений значком `🇷🇺`, а также кнопки **«Выбрать все»** / **«Снять все»**.
5. Настройки сохраняются мгновенно и применяются для **ByeDPI**, **WARP** и **VLESS**.

## 🛠️ Сборка проекта

### Требования:
- Android Studio Ladybug / Koala / Hedgehog (или новее) / JDK 17+
- Android SDK (API 35, Min SDK 26)
- NDK & CMake (для сборки нативных библиотек C/C++ и JNI)

### Сборка через командную строку:
```bash
# Windows
gradlew.bat assembleRelease

# Linux / macOS
./gradlew assembleRelease
```
Собранный APK будет находиться в папке: `app/build/outputs/apk/release/app-release.apk`.

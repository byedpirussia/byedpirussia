Универсальное Android-приложение для восстановления доступа к заблокированным ресурсам (YouTube, Discord, Telegram и др.) без необходимости аренды зарубежных серверов и сложных настроек.

Приложение объединяет в себе четыре независимых инструмента (ByeDPI, Telegram Proxy, AmneziaWG WARP, VLESS / Hysteria2 Reality), доступных прямо с главного экрана в 1 клик, гибкую систему **раздельного туннелирования (Split Tunneling)**, а также **кастомизацию оформления** (выбор акцентного цвета).

---

## 📖 Инструкция по использованию каждого метода

### 1. 🛡️ ByeDPI (Для YouTube, Discord и сайтов без потери скорости)
**Кому подходит**: Идеально для просмотра YouTube в 4K/60fps и голосовых каналов Discord на максимальной скорости вашего тарифа.
1. На главном экране нажмите кнопку **«Включить ByeDPI»**.
2. При первом запуске Android запросит стандартное разрешение на создание VPN-соединения — нажмите **«ОК»** (приложение работает локально на устройстве, никакой трафик на чужие серверы не уходит).
3. Статус сменится на `🟢 Активно`. Запустите YouTube или Discord — всё работает напрямую!
4. **Если YouTube не открывается или подтормаживает**:
   - Перейдите в **«Продвинутые настройки»** внизу экрана.
   - Нажмите **«⚡ Автоматический подбор стратегии»** — приложение само протестирует 32 комбинации и выберет ту, которая работает у вашего конкретного провайдера с минимальным пингом.
   - Либо выберите вручную пресет (например, *«OOB + Мультисплит»*, *«Split SNI»* или *«Fake Request»*).

---

### 2. ✈️ Telegram Proxy (MTProto over Cloudflare WebSocket)
**Кому подходит**: Для стабильной работы Telegram при блокировках и замедлениях мобильных операторов / провайдеров.
1. На главном экране найдите карточку **Telegram Proxy** и нажмите **«Включить Telegram Прокси»**.
2. Локальный прокси-сервер запустится на адресе `127.0.0.1:1443`.
3. Сразу после запуска появится синяя кнопка **«🚀 Применить в Telegram»** — нажмите её.
4. В открывшемся клиенте Telegram нажмите **«Включить этот прокси»** (Enable Proxy).
5. Теперь ваш Telegram подключен через Cloudflare WebSocket туннель!
> **Примечание**: Telegram Proxy можно использовать одновременно с ByeDPI или WARP.

---

### 3. 🌐 AmneziaWG Cloudflare WARP (Полноценный VPN-туннель)
**Кому подходит**: Для любых заблокированных сервисов и сайтов, требующих полноценного туннелирования всего трафика через Cloudflare с обфускацией AWG 2.0.
1. На главном экране нажмите **«Включить WARP»**.
2. Разрешите создание VPN-соединения в Android.
3. Статус сменится на `🟢 Подключен`. Весь интернет-трафик теперь надежно защищен от фильтрации ТСПУ благодаря случайным мусорным пакетам и измененным заголовкам WireGuard.
4. **Как обновить/сгенерировать новый WARP профиль**:
   - Откройте **«Продвинутые настройки»**.
   - В блоке **Конфигурация WARP** нажмите **«✨ Сгенерировать»** — приложение за пару секунд создаст свежий бесплатный профиль Cloudflare с уникальными ключами и защитными параметрами.
   - Вы также можете нажать **«📋 Скопировать»**, чтобы сохранить конфигурацию `.conf` или перенести её в стороннее приложение (AmneziaWG, WireGuard).
 
---
 
### 4. ⚡ VLESS / Reality (Xray Core)
**Кому подходит**: Для любых заблокированных сервисов и сайтов с использованием протокола VLESS, шифрования Reality, TLS, WebSocket и gRPC.
1. Нажмите **«Серверы VLESS»** на главном экране.
2. Добавьте свои VLESS-ключи (`+ vless://`) или целую подписку (`+ Подписка`).
3. Подписки разделены по удобным горизонтальным вкладкам с возможностью обновления (`🔄 Обновить`) и удаления.
4. Нажмите **«⚡ Тест пинга»** — приложение проверит доступность серверов через генерацию URL-теста и отсортирует их от самого быстрого к медленному.
5. Выберите нужный сервер и нажмите **«Включить VLESS»** на главном экране.

---

### 5. 🔀 Раздельное туннелирование (Split Tunneling)
**Кому подходит**: Если вы хотите пустить в обход только отдельные приложения (например, только YouTube и Discord), либо исключить российские банки и Госуслуги из туннеля.
1. Откройте **«Продвинутые настройки»** или иконку настроек в шапке приложения.
2. Нажмите на раздел **«Раздельное туннелирование»**.
3. Выберите один из трёх режимов:
   - **Весь трафик устройства (без исключений)** — стандартный режим, весь трафик направляется через выбранный метод обхода.
   - **Туннелировать только выбранные (Whitelist)** — только отмеченные галочками приложения будут работать через выбранный режим.
   - **Туннелировать всё, кроме выбранных (Blacklist)** — все приложения устройства работают через обход, кроме исключённых.
4. Доступен быстрый поиск по названию или пакету, а также кнопки **«Выбрать все»** / **«Снять все»**.
5. Настройки сохраняются мгновенно и применяются для **ByeDPI**, **WARP** и **VLESS**.

## 🛠️ Сборка проекта

### Требования:
- Android Studio Hedgehog (или новее) / JDK 17+
- Android SDK (API 34, Min SDK 26)
- NDK & CMake (для сборки нативных библиотек C/C++ и JNI)

### Сборка через командную строку:
```bash
# Windows
gradlew.bat assembleDebug

# Linux / macOS
./gradlew assembleDebug
```
Собранный APK будет находиться в папке: `app/build/outputs/apk/debug/app-debug.apk`.
